# 🍔 Foodie

A responsive food ordering landing page built with HTML, CSS, and JavaScript. The project showcases a modern restaurant UI with a featured menu, shopping cart functionality, customer testimonials, and a clean, user-friendly design.

## Features

- Responsive design for desktop and mobile
- Interactive shopping cart
- Popular food menu section
- Customer testimonials
- Newsletter subscription form
- Modern and clean user interface

## Tech Stack

- HTML5
- CSS3
- JavaScript

## Getting Started

Clone the repository:

```bash
git clone https://github.com/your-username/foodie.git
```

Open the project folder and launch `index.html` in your browser.
